# 野溪守護者 Wildstream Guardian

全端河川水質監測平台，提供水質資料視覺化、異常警示與回饋功能。

## 功能

- 水質監測站資料儀表板
- 異常偵測與即時警示
- 資料匯出
- 使用者回饋與商店頁

## 技術棧

| 層級 | 技術 |
|------|------|
| Backend | FastAPI (Python) + SQLite |
| Frontend | HTML / CSS / JavaScript |
| 部署 | Render (render.yaml) |

## 快速開始

```bash
pip install -r requirements.txt
python main.py
```
