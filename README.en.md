A full-stack river water-quality monitoring platform providing water-quality data visualisation, anomaly alerts and
feedback, with a multilingual interface (繁體中文 / 简体中文 / English / 日本語).

> **Live demo**: <https://tewei02.github.io/wildstream-guardian/>

## Live Demo

| Item | Details |
|------|------|
| URL | <https://tewei02.github.io/wildstream-guardian/> |
| Type | Pure static frontend, deployed on GitHub Pages (`docs/` directory), PWA offline-installable |
| Data | Simulated in real time in the browser; all features fully operable |

### Data Disclaimer

All monitoring values in the online demo (water temperature, pH, turbidity, dissolved oxygen, conductivity,
ammonia-nitrogen, total phosphorus), alert records and device statuses are randomly generated by the frontend
JavaScript according to rules — used only to showcase the interface and interaction flow; the seed data of the
backend version is likewise simulated. This project contains no real measurement results from any monitoring
station; please do not use it as a basis for water-quality interpretation or decisions.

## Features

| Feature | Description |
|------|------|
| Water-quality monitoring dashboard | Station data visualisation and live charts |
| Station management | Add, edit, delete and view station details (sample data) |
| Live data | Multi-parameter monitoring table, refreshed on a 30-second cycle (simulated fine-tuning) |
| Anomaly detection & alerts | Threshold checks on turbidity, pH and battery level, generating alert records |
| Map view | Leaflet map showing station distribution and latest readings |
| Historical trends | Multi-parameter line charts with statistical summaries (min / max / average) |
| Data export | Export CSV by station and date range |
| NB-IoT data intake | JSON uplink payload parsing and anomaly detection logs (simulated channel) |
| Multilingual support | zh-Hant / zh-Hans / en / ja |
| Offline install | Service Worker caching; installable as a desktop / mobile app (PWA) |

## Tech Stack

| Layer | Technology |
|------|------|
| Backend | FastAPI (Python) + SQLAlchemy + SQLite |
| Frontend | Jinja2 Templates + JavaScript + CSS |
| Online demo | Vanilla HTML / CSS / JavaScript + Leaflet 1.9.4 + Chart.js 4.4.0 + Service Worker |
| Deployment | GitHub Pages (static demo) / Render (`render.yaml`, full backend) |

## Quick Start

Browse online (no install needed):

```
https://tewei02.github.io/wildstream-guardian/
```

Run the full backend locally:

```bash
pip install -r requirements.txt
python main.py
```

Open <http://localhost:8000> after startup.

## Project Structure

```
wildstream-guardian/
├── docs/                     # Static demo (GitHub Pages source)
│   ├── index.html            # Single-page app: dashboard / stations / live / alerts / export / map / trends / devices / NB-IoT
│   ├── manifest.json         # PWA app info
│   ├── sw.js                 # Service Worker (offline cache)
│   ├── icons/                # PWA icons
│   └── vendor/               # Localised frontend dependencies (Leaflet / Chart.js)
├── main.py                   # Application entry point
├── config.py                 # Configuration
├── database/                 # Data models and seed data
├── routers/                  # API routes (dashboard / alerts / export / feedback / shop / stations)
├── services/                 # Business logic (anomaly detection, etc.)
├── templates/                # Page templates (incl. i18n multilingual)
├── static/                   # Frontend assets
└── render.yaml               # Render deployment config
```
